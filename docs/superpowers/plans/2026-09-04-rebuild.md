# migiwa rebuild 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `docs/superpowers/specs/2026-09-03-rebuild-design.md` の v1(Discord Gateway → Durable Object 内でセッション化 → SQLite → MCP `query`)を、既存コードを捨てて 13 の wave(= 13 PR)で作り直す。

**Architecture:** Worker 2 つ。`migiwa-bot`(`apps/bot`)は SQLite-backed Durable Object `BotObject` が Gateway 接続・セッション化・保存・purge を担い、cron が毎分 `ensureConnected()` を叩く。`migiwa-remote-mcp`(`apps/remote-mcp`)は `script_name` で `BotObject` に bind し、`POST /mcp`(ツール `query`)と `GET /health` を出す。純ロジックは `packages/{gateway,sessionizer,mcp,db}` に置いて `bun test`、Worker と DO は `@cloudflare/vitest-plugin` で実 workerd 上でテストする。

**Tech Stack:** bun workspaces + `workspaces.catalog`、TypeScript 7、Hono、`drizzle-orm/durable-sqlite` + `drizzle-kit`、`discord-api-types/v10`、`better-result`(Result / TaggedError)、`@modelcontextprotocol/sdk` + `@hono/mcp` + `zod`、wrangler、vitest + `@cloudflare/vitest-plugin`、oxlint / oxfmt / knip / lefthook / renovate / vite-plus(`vp run`)。

**Spec:** `docs/superpowers/specs/2026-09-03-rebuild-design.md`

## Global Constraints

- コード・コメント・README・commit・PR は英語。spec と plan(`docs/superpowers/`)は日本語(spec D10)。
- commit は gitmoji + `<type>(<scope>): <summary>`(imperative)。PR は `.github/pull_request_template.md` の構成。
- Bun のみ(npm / yarn / pnpm 禁止)。依存のバージョンは root `package.json` の `workspaces.catalog` に置き、各 workspace は `"catalog:"` で参照する。新しい依存は `npm view <pkg> time --json` で公開から 1 日以上経った最新版(renovate の `minimumReleaseAge: "1 day"` と同じ基準)を catalog に固定する。
- **lint と format**: plan のコードブロックは意図と構造を示すもので、そのままでは repo の oxlint(全カテゴリ error)と oxfmt を通らない箇所がある。各 task の implementer は commit 前に `bunx vp run oxfmt`(自動整形。import の並びもこれが直す)と `bunx vp run oxlint --deny-warnings` を通し、機械的な指摘(`one-var`、`curly`、`capitalized-comments`、`numeric-separators-style`、`no-await-expression-member`、`switch-case-braces`、`prefer-destructuring`、`no-plusplus`、`prefer-string-raw`、`array-type`、`init-declarations`、`prefer-named-capture-group`、`max-nested-calls`)は plan の意図を変えずに直す。構造を変えないと直らないものの扱い: `max-statements`(上限 10)は関数を private helper に分割する。`no-continue` は `if` の入れ子か `filter` に書き換える。`default-case` は `default: { return []; }` を足す。`no-bitwise`(`INTENTS` の OR)と `no-await-in-loop`(`waitFor` のポーリング)は理由付きの `// oxlint-disable-next-line <rule> -- <why>` で抑止する。`no-non-null-assertion` はテストでも使わず `?? fail()` か `expect(...).toBeDefined()` で絞る。
- **各 task の検証**: task に書かれた検証コマンドに加え、commit 前に必ず `bun dedupe --check` と `bunx vp run oxfmt --check` を通す(PR テンプレートの Testing 欄がこれを要求する)。
- `apps/*` は薄い deploy 単位、`packages/*` は `@migiwa/<name>` のソース専用パッケージ(`exports` は `./src/*.ts`、bundle しない)。
- Worker app: `entry.ts` は handler の配線だけ。`server.ts` は `export const app = new Hono<HonoEnv>()` から 1 本のメソッドチェーン。route は `*Route`、middleware は `*Middleware`。`HonoEnv` は `server.ts` で定義し、route からは `import type`。
- テスト: `packages/*` は `bun test`(`test/*.spec.ts`)。DO や binding を触る `apps/*` は vitest + `@cloudflare/vitest-plugin`、config は deploy と同じ `wrangler.jsonc` を指す。Worker は `exports.default.fetch()`、DO の中は `runInDurableObject`。
- 生成物(`apps/*/worker-configuration.d.ts`、`packages/db/drizzle/**`)は `.gitattributes` に `linguist-generated=true`、手で編集しない。`drizzle/migrations.d.ts` だけは手書きの例外。
- Cloudflare 以外に依存しない(Discord Gateway を除く)。Containers / Queues / Pipelines / D1 / protobuf は使わない。
- DO インスタンスは `idFromName("default")` の 1 つ。`locationHint` なし。RPC 名に `connect` を使わない(`Fetcher.connect` と衝突)。alarm に渡す時刻は整数。
- gateway 状態(`session_id`、`seq` など)は `ctx.storage.kv`(同期 API)の `"gateway"` キー。SQL テーブルに置かない。
- `message` ハンドラは同期関数。dispatch 1 件 = `ctx.storage.transactionSync` 1 つ。`db.transaction()` に async コールバックを渡さない。
- 取り込むイベントは `PRESENCE_UPDATE` と `VOICE_STATE_UPDATE` に固定。intents は `Guilds | GuildVoiceStates | GuildPresences` 固定(spec D8)。
- 生 payload をログに出さない。ログは JSON 1 行(`console.log(JSON.stringify({ event, ... }))`)。
- **エラーは `Result`(spec D12)**: 失敗しうる関数は `better-result` の `Result<T, E>` を返し、`E` は `TaggedError("Name")<{ …; message: string }>` のサブクラス。合成は `Result.gen`(async なら `async function*` と `Result.await`)、分岐は `.match({ ok, err })` と `error.match({ Tag: … })`。`throw` はバグにだけ。DO の RPC メソッド(`BotObject.query()` など)と MCP ツールの応答は structured clone なので、その境界では `Err` を `throw new Error(error.message)` に戻す。API の正確な形(`Result.try({ try, catch })`、`Result.tryPromise`、`yield* new TaggedError(...)` での短絡)は最初に使う task で `node_modules/better-result` の型定義を見て確かめる。
- 時刻は整数の Unix ミリ秒。列名は snake_case、Drizzle の `casing` は使わない。
- 環境変数: bot = `DISCORD_BOT_TOKEN`(secret)、`DISCORD_GUILD_IDS`(空 = 全 guild)、`RAW_EVENT_RETENTION_DAYS`(7)、`RETENTION_DAYS`(30)。remote-mcp = `API_TOKEN`(secret)、DO binding `BOT`(`class_name: BotObject`, `script_name: migiwa-bot`)。
- deploy は Cloudflare Workers Builds。GitHub Actions は deploy しない。CI の `wrangler deploy --dry-run` だけがバンドルを検査する。
- 各 wave の作業前に `git switch -c rebuild-w<N> <前の branch>`(wave 1 は `rebuild`、wave N は `rebuild-w<N-1>`)。PR は `gh pr create --base <前の branch>` で積む(2026-09-04 決定: repo の `create-pr` スキルの `feat/<slug>` 命名と `gh stack` は使わず、PR タイトルの gitmoji 形式とテンプレートだけ従う)。全ステップの検証コマンドは worktree のルートで実行する。

`packages/db/src/schemas/presence-sessions.ts`:

```ts
import { sql } from "drizzle-orm";
import { integer, sqliteTable, text, uniqueIndex } from "drizzle-orm/sqlite-core";

import type { EndReason } from "./end-reasons";

export type PresenceStatus = "online" | "idle" | "dnd";

// One row per stretch of a single presence status for a user in a guild. An open session is
// `ended_at IS NULL`; the partial unique index is what enforces "at most one open session per
// (guild, user)" and keeps the lookup O(log n). Presence is stored per guild, as Discord
// delivers it, so a user shared by three guilds has three rows.
export const presence_sessions = sqliteTable(
  "presence_sessions",
  {
    id: integer().primaryKey({ autoIncrement: true }),
    guild_id: text().notNull(),
    user_id: text().notNull(),
    status: text().$type<PresenceStatus>().notNull(),
    client_desktop: text(),
    client_mobile: text(),
    client_web: text(),
    started_at: integer().notNull(),
    ended_at: integer(),
    end_reason: text().$type<EndReason>(),
  },
  (t) => [
    uniqueIndex("presence_sessions_open_uidx")
      .on(t.guild_id, t.user_id)
      .where(sql`${t.ended_at} IS NULL`),
  ],
);
```

`apps/bot/src/bot-object.ts`:

```ts
import type { DatabaseClient } from "@migiwa/db";
import type { StatusReport } from "@migiwa/gateway";

import { createDatabaseClient } from "@migiwa/db";
import migrations from "@migiwa/db/migrations";
import { stoppedStatus } from "@migiwa/gateway";
import { DurableObject } from "cloudflare:workers";
import { migrate } from "drizzle-orm/durable-sqlite/migrator";

export class BotObject extends DurableObject<Cloudflare.Env> {
  public readonly db: DatabaseClient;

  public constructor(ctx: DurableObjectState, env: Cloudflare.Env) {
    super(ctx, env);
    this.db = createDatabaseClient(ctx.storage);
    // Every RPC may assume the schema exists: blockConcurrencyWhile holds every other call on
    // this object until the callback settles. Drizzle's journal makes re-running it on each
    // restart a no-op.
    void ctx.blockConcurrencyWhile(async () => migrate(this.db, migrations));
  }

  // The gateway client arrives in wave 7; until then the bot is honestly "stopped".
  // oxlint-disable-next-line class-methods-use-this -- DO RPC dispatches to instance methods only.
  public async status(): Promise<StatusReport> {
    return stoppedStatus();
  }

  // Called by the cron every minute (spec §5.2). Not named `connect`: that collides with
  // Fetcher.connect on the stub.
  public async ensureConnected(): Promise<StatusReport> {
    return this.status();
  }
}
```

```ts
import type { GatewayReceivePayload } from "discord-api-types/v10";

import { Result, TaggedError } from "better-result";

export type MalformedFrameReason =
  | "binary"
  | "invalid_json"
  | "not_object"
  | "bad_op"
  | "bad_s"
  | "bad_t";

// Why a frame was dropped before dispatch (spec §5.4, D12). The reason is what the ingest
// counters log; the payload itself never is.
export class MalformedFrame extends TaggedError("MalformedFrame")<{
  reason: MalformedFrameReason;
  message: string;
}> {}

const malformed = (reason: MalformedFrameReason): Result<never, MalformedFrame> =>
  Result.err(new MalformedFrame({ reason, message: `gateway frame dropped: ${reason}` }));

// Envelope guard only (spec §5.4): `op`, `s` and `t` are checked, `d` is trusted and narrowed
// by `t` through discord-api-types. Discord is a trusted upstream; validating every
// GUILD_CREATE payload would burn CPU for nothing. Discord always sends all four fields
// (`s` and `t` are null outside dispatches), so a missing one is treated as malformed.
export function parseGatewayMessage(raw: unknown): Result<GatewayReceivePayload, MalformedFrame> {
  if (typeof raw !== "string") return malformed("binary");
  const parsed = Result.try({
    try: (): unknown => JSON.parse(raw),
    catch: () => new MalformedFrame({ reason: "invalid_json", message: "frame is not JSON" }),
  });
  if (parsed.isErr()) return Result.err(parsed.error);
  const value = parsed.value;
  if (typeof value !== "object" || value === null) return malformed("not_object");
  const { op, s, t } = value as { op?: unknown; s?: unknown; t?: unknown };
  if (typeof op !== "number") return malformed("bad_op");
  if (s !== null && typeof s !== "number") return malformed("bad_s");
  if (t !== null && typeof t !== "string") return malformed("bad_t");
  return Result.ok(value as GatewayReceivePayload);
}
```

```ts
import { GatewayCloseCodes } from "discord-api-types/v10";

export type CloseDecision =
  | { kind: "resume" }
  | { kind: "identify" }
  | { kind: "fatal"; reason: string };

// Codes after which Discord forbids RESUME but allows a fresh IDENTIFY (spec §5.7).
const IDENTIFY_CODES: ReadonlySet<number> = new Set([
  GatewayCloseCodes.NotAuthenticated,
  GatewayCloseCodes.InvalidSeq,
  GatewayCloseCodes.SessionTimedOut,
]);

// Codes no reconnect can fix: a human has to change the token, intents or shard config.
const FATAL_CODES: ReadonlyMap<number, string> = new Map([
  [GatewayCloseCodes.AuthenticationFailed, "authentication_failed"],
  [GatewayCloseCodes.InvalidShard, "invalid_shard"],
  [GatewayCloseCodes.ShardingRequired, "sharding_required"],
  [GatewayCloseCodes.InvalidAPIVersion, "invalid_api_version"],
  [GatewayCloseCodes.InvalidIntents, "invalid_intents"],
  [GatewayCloseCodes.DisallowedIntents, "disallowed_intents"],
]);

// Everything else (network drops, 1006, 4000, a zombie we closed ourselves) is resumable.
export function decideOnClose(code: number | undefined): CloseDecision {
  if (code === undefined) return { kind: "resume" };
  const fatal = FATAL_CODES.get(code);
  if (fatal !== undefined) return { kind: "fatal", reason: fatal };
  if (IDENTIFY_CODES.has(code)) return { kind: "identify" };
  return { kind: "resume" };
}
```

```ts
const BASE_MS = 1_000;
const MAX_MS = 300_000;

// 1 s × 2^attempt capped at five minutes, then ±25 % jitter (spec §5.7).
export function backoffDelayMs(attempt: number, random: () => number = Math.random): number {
  const base = Math.min(BASE_MS * 2 ** attempt, MAX_MS);
  return Math.round(base * (0.75 + random() * 0.5));
}

// Discord asks for a 1–5 s wait after Invalid Session before the next IDENTIFY / RESUME.
export function invalidSessionDelayMs(random: () => number = Math.random): number {
  return Math.round(1_000 + random() * 4_000);
}

// After a fatal close code the next attempt waits an hour: the daily IDENTIFY budget is 1,000
// and a misconfigured bot must not burn it (spec §5.7).
export const FATAL_RETRY_MS = 3_600_000;

// IDENTIFYs kept in reserve out of the daily budget reported by GET /gateway/bot (spec §5.3).
export const IDENTIFY_RESERVE = 50;
```

```ts
export interface HeartbeatState {
  readonly intervalMs: number;
  readonly lastSentAt: number | null;
  readonly lastAckAt: number | null;
  readonly nextDueAt: number;
}

// Discord's rule: the first heartbeat goes out after interval × random(), then every interval.
export function heartbeatOnHello(
  intervalMs: number,
  now: number,
  random: () => number = Math.random,
): HeartbeatState {
  return {
    intervalMs,
    lastSentAt: null,
    lastAckAt: null,
    nextDueAt: now + Math.floor(intervalMs * random()),
  };
}

export function heartbeatOnSend(state: HeartbeatState, now: number): HeartbeatState {
  return { ...state, lastSentAt: now, nextDueAt: now + state.intervalMs };
}

export function heartbeatOnAck(state: HeartbeatState, now: number): HeartbeatState {
  return { ...state, lastAckAt: now };
}

export function isHeartbeatDue(state: HeartbeatState, now: number): boolean {
  return now >= state.nextDueAt;
}

// A heartbeat went out and its ACK never came back before the next one is due: Discord calls
// this a zombied connection and wants a non-1000 close followed by RESUME (spec §5.5).
export function isZombie(state: HeartbeatState, now: number): boolean {
  return (
    state.lastSentAt !== null &&
    (state.lastAckAt === null || state.lastAckAt < state.lastSentAt) &&
    isHeartbeatDue(state, now)
  );
}

// ensureConnected() treats a socket as fine while heartbeats keep up: nothing is overdue by
// more than an interval (a dead alarm chain shows up here) and the last one was acknowledged.
export function isHealthy(state: HeartbeatState, now: number): boolean {
  return !isZombie(state, now) && now < state.nextDueAt + state.intervalMs;
}
```

`packages/db/src/read-only.ts`:

```ts
import { Result, TaggedError } from "better-result";

export type NotReadOnlyReason = "not_a_query" | "multiple_statements" | "forbidden_keyword";

// Why a statement was refused (spec §7.3, D12). BotObject.query() turns this into a throw at
// the RPC boundary; the message is what the MCP client sees.
export class NotReadOnlySql extends TaggedError("NotReadOnlySql")<{
  reason: NotReadOnlyReason;
  message: string;
}> {}

// Leading whitespace, `-- line` comments and `/* block */` comments before the statement.
const LEADING_NOISE = /^(?:\s+|--[^\n]*(?:\n|$)|\/\*[\s\S]*?\*\/)+/;
const READ_ONLY_HEAD = /^(?:select|with|explain)\b/i;
const FORBIDDEN = /\b(?:pragma|attach)\b/i;

const refuse = (reason: NotReadOnlyReason): Result<never, NotReadOnlySql> =>
  Result.err(
    new NotReadOnlySql({
      reason,
      message: `only a single SELECT / WITH / EXPLAIN statement is allowed (${reason})`,
    }),
  );

// Read-only guard for BotObject.query() (spec §7.3): one statement, starting with SELECT /
// WITH / EXPLAIN, no PRAGMA or ATTACH. SQLite cannot write through a SELECT, so this is
// sufficient. A `;` inside a string literal is rejected too; that is a deliberate
// simplification, not a bug. Ok carries the statement without its trailing `;`.
export function ensureReadOnly(sql: string): Result<string, NotReadOnlySql> {
  const body = sql.replace(LEADING_NOISE, "").trim();
  if (!READ_ONLY_HEAD.test(body)) return refuse("not_a_query");
  const statement = body.replace(/;\s*$/, "");
  if (statement.includes(";")) return refuse("multiple_statements");
  if (FORBIDDEN.test(statement)) return refuse("forbidden_keyword");
  return Result.ok(statement);
}
```

```ts
import type { QueryResult } from "@migiwa/gateway";

import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { z } from "zod";

export interface McpDeps {
  description: string;
  query: (sql: string) => Promise<QueryResult>;
}

// Exactly one tool (spec D7). The description is what teaches the model the schema, so the
// caller builds it from the live sqlite_master and passes it in.
export function createMcpServer(deps: McpDeps): McpServer {
  const server = new McpServer({ name: "migiwa", version: "1.0.0" });
  server.registerTool(
    "query",
    { description: deps.description, inputSchema: { sql: z.string() } },
    async ({ sql }) => {
      try {
        const result = await deps.query(sql);
        return { content: [{ type: "text", text: JSON.stringify(result) }] };
      } catch (error) {
        const text = error instanceof Error ? error.message : String(error);
        return { isError: true, content: [{ type: "text", text }] };
      }
    },
  );
  return server;
}
```

```ts
import type { QueryResult, StatusReport, TableInfo } from "@migiwa/gateway";

import { createDatabaseClient, ensureReadOnly } from "@migiwa/db";

// Rows a single query() may return (spec §7.3).
const MAX_ROWS = 10_000;

  // Feeds the MCP tool description (spec §7.2): user tables only, without SQLite's own tables,
  // drizzle's journal and workerd's `_cf_*` internals.
  public async schema(): Promise<TableInfo[]> {
    return this.ctx.storage.sql
      .exec<TableInfo>(
        "SELECT name, sql FROM sqlite_master WHERE type = 'table' " +
          "AND name NOT LIKE 'sqlite\\_%' ESCAPE '\\' " +
          "AND name NOT LIKE '\\_\\_%' ESCAPE '\\' " +
          "AND name NOT LIKE '\\_cf\\_%' ESCAPE '\\' ORDER BY name",
      )
      .toArray();
  }

  // Read-only SQL for the MCP tool (spec §7.3). Raw exec on purpose: the SQL is the user's,
  // so Drizzle's query builder has nothing to add here.
  public async query(sql: string): Promise<QueryResult> {
    // RPC boundary (spec D12): a Result cannot cross structured clone, so Err becomes a throw
    // and the MCP tool turns it into an isError response.
    const statement = ensureReadOnly(sql);
    if (statement.isErr()) throw new Error(statement.error.message);
    const cursor = this.ctx.storage.sql.exec(statement.value);
    const rows: unknown[][] = [];
    let truncated = false;
    for (const row of cursor.raw()) {
      if (rows.length >= MAX_ROWS) {
        truncated = true;
        break;
      }
      rows.push(row);
    }
    return { columns: cursor.columnNames, rows, rows_read: cursor.rowsRead, truncated };
  }
```

```ts
import type { GatewayState, StatusReport } from "@migiwa/gateway";

export const GATEWAY_KEY = "gateway";
const DAY_MS = 86_400_000;

// Everything the gateway client must survive a restart with (spec §5.1). Lives in
// ctx.storage.kv, never in SQL, so the MCP query tool cannot reach the session id.
export interface GatewayStore {
  session_id: string | null;
  seq: number | null;
  resume_gateway_url: string | null;
  status: GatewayState;
  status_reason: string | null;
  status_since: number;
  backoff_until: number | null;
  backoff_attempt: number;
  identify_remaining: number | null;
  identify_reset_at: number | null;
  last_ack_at: number | null;
  last_heartbeat_at: number | null;
  last_event_at: number | null;
  disconnected_at: number | null;
  bot_user_id: string | null;
  // Timestamps of connect attempts, pruned to the last 24 hours (status().reconnects_24h).
  reconnects: number[];
}

export function initialGatewayStore(now: number): GatewayStore {
  return {
    session_id: null,
    seq: null,
    resume_gateway_url: null,
    status: "stopped",
    status_reason: null,
    status_since: now,
    backoff_until: null,
    backoff_attempt: 0,
    identify_remaining: null,
    identify_reset_at: null,
    last_ack_at: null,
    last_heartbeat_at: null,
    last_event_at: null,
    disconnected_at: null,
    bot_user_id: null,
    reconnects: [],
  };
}

export function readGateway(kv: SyncKvStorage, now: number): GatewayStore {
  return kv.get<GatewayStore>(GATEWAY_KEY) ?? initialGatewayStore(now);
}

export function writeGateway(kv: SyncKvStorage, store: GatewayStore): void {
  kv.put(GATEWAY_KEY, store);
}

// `disconnected_at` is what GUILD_CREATE reconciliation uses as ended_at for users that went
// away while the bot was down (spec §6.3), so it is stamped exactly when "connected" ends.
export function withStatus(
  store: GatewayStore,
  status: GatewayState,
  reason: string | null,
  now: number,
): GatewayStore {
  if (store.status === status && store.status_reason === reason) return store;
  const lostConnection = store.status === "connected" && status !== "connected";
  return {
    ...store,
    status,
    status_reason: reason,
    status_since: now,
    disconnected_at: lostConnection ? now : store.disconnected_at,
  };
}

// After close codes that forbid RESUME (spec §5.7).
export function clearSession(store: GatewayStore): GatewayStore {
  return { ...store, session_id: null, seq: null, resume_gateway_url: null };
}

export function recordReconnect(store: GatewayStore, now: number): GatewayStore {
  const recent = store.reconnects.filter((at) => at > now - DAY_MS);
  return { ...store, reconnects: [...recent, now] };
}

export function toStatusReport(store: GatewayStore, guildCount: number, now: number): StatusReport {
  return {
    state: store.status,
    since: store.status_since,
    reason: store.status_reason,
    last_event_at: store.last_event_at,
    seq: store.seq,
    guild_count: guildCount,
    reconnects_24h: store.reconnects.filter((at) => at > now - DAY_MS).length,
    identify_remaining: store.identify_remaining,
  };
}
```

```js
        t: "READY",
        d: {
          v: 10,
          user: { id: "bot-1" },
          session_id: options.sessionId,
          resume_gateway_url: options.resumeGatewayUrl,
          guilds: [],
        },
      });
    } else if (frame.op === 6) {
      send({ op: 0, s: frame.d.seq + 1, t: "RESUMED", d: {} });
    } else if (frame.op === 1 && options.ackHeartbeats) {
      send({ op: 11, s: null, t: null, d: null });
    }
  });
  socket.addEventListener("close", () => {
    if (server === socket) server = null;
  });
  send({ op: 10, s: null, t: null, d: { heartbeat_interval: options.heartbeatInterval } });
  return new Response(null, { status: 101, webSocket: client });
}

async function control(url, request) {
  switch (url.pathname) {
    case "/received":
      return Response.json(received);
    case "/options":
      options = { ...options, ...(await request.json()) };
      return new Response(null, { status: 204 });
    case "/send":
      send(await request.json());
      return new Response(null, { status: 204 });
    case "/close": {
      const { code, reason } = await request.json();
      server?.close(code, reason);
      return new Response(null, { status: 204 });
    }
    case "/reset":
      server?.close(1000, "reset");
      server = null;
      received = [];
      options = { ...DEFAULTS };
      return new Response(null, { status: 204 });
    default:
      return new Response("unknown control path", { status: 404 });
  }
}

export default {
  async fetch(request) {
    const url = new URL(request.url);
    if (url.host === "discord.com" && url.pathname === "/api/v10/gateway/bot") {
      if (options.gatewayBotStatus !== 200) {
        return new Response("nope", { status: options.gatewayBotStatus });
      }
      return Response.json({
        url: "wss://gateway.discord.gg",
        shards: 1,
        session_start_limit: {
          total: 1000,
          remaining: options.remaining,
          reset_after: 3_600_000,
          max_concurrency: 1,
        },
      });
    }
    if (url.host.endsWith(".discord.gg")) {
      if (request.headers.get("Upgrade") !== "websocket") {
        return new Response("expected a websocket upgrade", { status: 426 });
      }
      return openGateway();
    }
    if (url.host === "mock") return control(url, request);
    return new Response(`not mocked: ${request.url}`, { status: 502 });
  },
};
```

```ts
import type { APIGatewayBotInfo } from "discord-api-types/v10";

import { GATEWAY_BOT_ENDPOINT } from "@migiwa/gateway";
import { Result } from "better-result";

import { GatewayBotFailed, UpgradeFailed } from "./gateway-errors";

const USER_AGENT = "DiscordBot (https://github.com/taiki-kuraishi/migiwa, 1.0.0)";

const describeError = (error: unknown): string =>
  error instanceof Error ? error.message : String(error);

// GET /gateway/bot: where to connect, how many shards Discord wants, and today's IDENTIFY
// budget (spec §5.3). A 401 is the token being wrong; the caller treats it as fatal.
export function fetchGatewayBot(
  token: string,
): Promise<Result<APIGatewayBotInfo, GatewayBotFailed>> {
  return Result.gen(async function* () {
    const response = yield* Result.await(
      Result.tryPromise({
        try: () =>
          fetch(GATEWAY_BOT_ENDPOINT, {
            headers: { Authorization: `Bot ${token}`, "User-Agent": USER_AGENT },
          }),
        catch: (error) =>
          new GatewayBotFailed({
            status: null,
            message: `GET /gateway/bot unreachable: ${describeError(error)}`,
          }),
      }),
    );
    if (!response.ok) {
      return Result.err(
        new GatewayBotFailed({
          status: response.status,
          message: `GET /gateway/bot failed with ${response.status}`,
        }),
      );
    }
    const info = yield* Result.await(
      Result.tryPromise({
        try: (): Promise<APIGatewayBotInfo> => response.json(),
        catch: (error) =>
          new GatewayBotFailed({
            status: response.status,
            message: `GET /gateway/bot returned no JSON: ${describeError(error)}`,
          }),
      }),
    );
    return Result.ok(info);
  });
}

// fetch() + Upgrade instead of `new WebSocket()`: the latter adds permessage-deflate, which
// Discord does not negotiate the way we want (spec §5.3). The socket comes back accepted;
// the caller attaches its listeners.
export function openGatewaySocket(url: string): Promise<Result<WebSocket, UpgradeFailed>> {
  return Result.gen(async function* () {
    const response = yield* Result.await(
      Result.tryPromise({
        try: () => fetch(url, { headers: { Upgrade: "websocket" } }),
        catch: (error) =>
          new UpgradeFailed({ status: null, message: `gateway unreachable: ${describeError(error)}` }),
      }),
    );
    const socket = response.webSocket;
    if (socket === null) {
      return Result.err(
        new UpgradeFailed({
          status: response.status,
          message: `gateway upgrade failed with ${response.status}`,
        }),
      );
    }
    socket.accept();
    return Result.ok(socket);
  });
}
```

```ts
import type { DatabaseClient } from "@migiwa/db";
import type { HeartbeatState, QueryResult, StatusReport, TableInfo } from "@migiwa/gateway";
import type { GatewayDispatchPayload } from "discord-api-types/v10";

import { createDatabaseClient, ensureReadOnly, guilds } from "@migiwa/db";
import migrations from "@migiwa/db/migrations";
import {
  backoffDelayMs,
  FATAL_RETRY_MS,
  gatewayHttpUrl,
  heartbeatOnAck,
  heartbeatOnHello,
  heartbeatOnSend,
  heartbeatPayload,
  IDENTIFY_RESERVE,
  identifyPayload,
  isHealthy,
  isHeartbeatDue,
  isZombie,
  parseGatewayMessage,
} from "@migiwa/gateway";
import { Result } from "better-result";
import { DurableObject } from "cloudflare:workers";
import { GatewayDispatchEvents, GatewayOpcodes } from "discord-api-types/v10";
import { count, eq } from "drizzle-orm";
import { migrate } from "drizzle-orm/durable-sqlite/migrator";

import type { ConnectError } from "./gateway-errors";
import type { GatewayStore } from "./gateway-state";

import { fetchGatewayBot, openGatewaySocket } from "./discord-rest";
import { IdentifyBudgetExhausted, ShardingRequired } from "./gateway-errors";
import {
  readGateway,
  recordReconnect,
  toStatusReport,
  withStatus,
  writeGateway,
} from "./gateway-state";
import { log } from "./log";

// Rows a single query() may return (spec §7.3).
const MAX_ROWS = 10_000;
// A connect() that has not produced a HELLO within this window is treated as stuck.
const CONNECT_GRACE_MS = 60_000;
// When alarm() itself throws, try again this much later so the chain never ends silently.
const FALLBACK_ALARM_MS = 30_000;

export class BotObject extends DurableObject<Cloudflare.Env> {
  public readonly db: DatabaseClient;

  // In-memory only: an outbound socket never survives a restart, so neither does its
  // heartbeat bookkeeping. Everything that must survive is in gateway-state.ts.
  private socket: WebSocket | null = null;
  private heartbeat: HeartbeatState | null = null;
  private connecting: Promise<void> | null = null;

  public constructor(ctx: DurableObjectState, env: Cloudflare.Env) {
    super(ctx, env);
    this.db = createDatabaseClient(ctx.storage);
    // Every RPC may assume the schema exists: blockConcurrencyWhile holds every other call on
    // this object until the callback settles. Drizzle's journal makes re-running it on each
    // restart a no-op.
    void ctx.blockConcurrencyWhile(async () => migrate(this.db, migrations));
  }

  public async status(): Promise<StatusReport> {
    const now = Date.now();
    return toStatusReport(readGateway(this.ctx.storage.kv, now), this.guildCount(), now);
  }

  // Called by the cron every minute (spec §5.2). Not named `connect`: that collides with
  // Fetcher.connect on the stub.
  public async ensureConnected(): Promise<StatusReport> {
    const now = Date.now();
    const store = readGateway(this.ctx.storage.kv, now);
    const waiting = store.backoff_until !== null && store.backoff_until > now;
    const open = this.socket?.readyState === WebSocket.READY_STATE_OPEN;
    const healthy = open && this.heartbeat !== null && isHealthy(this.heartbeat, now);
    const settling =
      this.connecting !== null ||
      (open && this.heartbeat === null && now - store.status_since < CONNECT_GRACE_MS);
    if (!waiting && !healthy && !settling) await this.connect();
    return this.status();
  }

  // Feeds the MCP tool description (spec §7.2): user tables only, without SQLite's own tables,
  // drizzle's journal and workerd's `_cf_*` internals.
  public async schema(): Promise<TableInfo[]> {
    return this.ctx.storage.sql
      .exec<TableInfo>(
        "SELECT name, sql FROM sqlite_master WHERE type = 'table' " +
          "AND name NOT LIKE 'sqlite\\_%' ESCAPE '\\' " +
          "AND name NOT LIKE '\\_\\_%' ESCAPE '\\' " +
          "AND name NOT LIKE '\\_cf\\_%' ESCAPE '\\' ORDER BY name",
      )
      .toArray();
  }

  // Read-only SQL for the MCP tool (spec §7.3). Raw exec on purpose: the SQL is the user's,
  // so Drizzle's query builder has nothing to add here.
  public async query(sql: string): Promise<QueryResult> {
    // RPC boundary (spec D12): a Result cannot cross structured clone, so Err becomes a throw
    // and the MCP tool turns it into an isError response.
    const statement = ensureReadOnly(sql);
    if (statement.isErr()) throw new Error(statement.error.message);
    const cursor = this.ctx.storage.sql.exec(statement.value);
    const rows: unknown[][] = [];
    let truncated = false;
    for (const row of cursor.raw()) {
      if (rows.length >= MAX_ROWS) {
        truncated = true;
        break;
      }
      rows.push(row);
    }
    return { columns: cursor.columnNames, rows, rows_read: cursor.rowsRead, truncated };
  }

  // Heartbeats and the reconnect timer share this one alarm (spec §5.5). Alarms, unlike
  // timers, keep the object alive, which is what makes the socket outlive the 70 s idle rule.
  public async alarm(): Promise<void> {
    try {
      const now = Date.now();
      if (this.socket !== null && this.heartbeat !== null && isHeartbeatDue(this.heartbeat, now)) {
        if (isZombie(this.heartbeat, now)) {
          log("zombie");
          this.socket.close(4000, "heartbeat ack missing");
        } else {
          this.sendHeartbeat(now);
        }
      }
      const store = readGateway(this.ctx.storage.kv, now);
      if (store.backoff_until !== null && store.backoff_until <= now) await this.connect();
      this.scheduleAlarm(Date.now());
    } catch (error) {
      log("alarm_error", { message: error instanceof Error ? error.message : String(error) });
      await this.ctx.storage.setAlarm(Date.now() + FALLBACK_ALARM_MS);
    }
  }

  // Serialises overlapping callers (a cron tick racing the alarm) onto one attempt.
  private connect(): Promise<void> {
    this.connecting ??= this.doConnect().finally(() => {
      this.connecting = null;
    });
    return this.connecting;
  }

  // The only async path in the object (spec §5.3). One Result.gen railway: every way it can
  // fail is a TaggedError from gateway-errors.ts and onConnectError() matches them all.
  private async doConnect(): Promise<void> {
    const kv = this.ctx.storage.kv;
    const now = Date.now();
    this.dropSocket();
    writeGateway(kv, withStatus(recordReconnect(readGateway(kv, now), now), "connecting", null, now));
    const token = this.env.DISCORD_BOT_TOKEN;
    const attempt = await Result.gen(async function* () {
      const info = yield* Result.await(fetchGatewayBot(token));
      const limit = info.session_start_limit;
      const then = Date.now();
      writeGateway(kv, {
        ...readGateway(kv, then),
        identify_remaining: limit.remaining,
        identify_reset_at: then + limit.reset_after,
      });
      if (info.shards > 1) {
        return Result.err(
          new ShardingRequired({
            shards: info.shards,
            message: `Discord wants ${info.shards} shards; v1 runs exactly one`,
          }),
        );
      }
      if (limit.remaining < IDENTIFY_RESERVE) {
        return Result.err(
          new IdentifyBudgetExhausted({
            remaining: limit.remaining,
            reset_after: limit.reset_after,
            message: `only ${limit.remaining} IDENTIFYs left today; keeping ${IDENTIFY_RESERVE} in reserve`,
          }),
        );
      }
      const socket = yield* Result.await(openGatewaySocket(gatewayHttpUrl(info.url)));
      return Result.ok(socket);
    });
    attempt.match({
      ok: (socket) => this.adoptSocket(socket),
      err: (error) => this.onConnectError(error),
    });
  }

  // Listeners are attached here rather than in discord-rest.ts because they need `this`.
  private adoptSocket(socket: WebSocket): void {
    this.socket = socket;
    this.heartbeat = null;
    socket.addEventListener("message", (event) => this.onMessage(event.data));
    socket.addEventListener("close", (event) => this.onClose(socket, event.code, event.reason));
    socket.addEventListener("error", () => this.onClose(socket, undefined, "socket_error"));
    log("socket_open");
  }

  // Spec §5.3 step 4 and §5.7: which failure means fatal (a human must act), wait (Discord
  // said when) or backoff. Exhaustive over ConnectError by construction.
  private onConnectError(error: ConnectError): void {
    const now = Date.now();
    const kv = this.ctx.storage.kv;
    error.match({
      GatewayBotFailed: (failure) => {
        if (failure.status === 401) {
          this.fail(readGateway(kv, now), "authentication_failed", now);
        } else {
          this.scheduleReconnect(failure.message);
        }
      },
      ShardingRequired: () => this.fail(readGateway(kv, now), "sharding_required", now),
      IdentifyBudgetExhausted: (budget) => {
        const waiting = { ...readGateway(kv, now), backoff_until: now + budget.reset_after };
        writeGateway(kv, withStatus(waiting, "backoff", "identify_budget", now));
        log("identify_budget", { remaining: budget.remaining, reset_after: budget.reset_after });
        this.scheduleAlarm(now);
      },
      UpgradeFailed: (upgrade) => this.scheduleReconnect(upgrade.message),
    });
  }

  // Synchronous on purpose (spec §5.4): the event loop then delivers frames in order and no
  // promise chain or re-entrancy guard is needed. Nothing here closes the socket on an
  // application error; it is logged and the next frame is processed.
  private onMessage(data: string | ArrayBuffer): void {
    try {
      const parsed = parseGatewayMessage(data);
      if (parsed.isErr()) {
        log("frame_dropped", { reason: parsed.error.reason });
        return;
      }
      const message = parsed.value;
      const now = Date.now();
      switch (message.op) {
        case GatewayOpcodes.Hello:
          this.onHello(message.d.heartbeat_interval, now);
          break;
        case GatewayOpcodes.Heartbeat:
          this.sendHeartbeat(now);
          break;
        case GatewayOpcodes.HeartbeatAck:
          this.onHeartbeatAck(now);
          break;
        case GatewayOpcodes.Dispatch:
          this.onDispatch(message, now);
          break;
        default:
          break;
      }
    } catch (error) {
      log("message_error", { message: error instanceof Error ? error.message : String(error) });
    }
  }

  private onHello(intervalMs: number, now: number): void {
    if (this.socket === null) return;
    this.heartbeat = heartbeatOnHello(intervalMs, now);
    const kv = this.ctx.storage.kv;
    const store = readGateway(kv, now);
    this.socket.send(identifyPayload(this.env.DISCORD_BOT_TOKEN));
    const remaining = store.identify_remaining === null ? null : store.identify_remaining - 1;
    writeGateway(kv, { ...store, identify_remaining: remaining });
    log("identify", { identify_remaining: remaining });
    this.scheduleAlarm(now);
  }

  private onHeartbeatAck(now: number): void {
    if (this.heartbeat === null) return;
    this.heartbeat = heartbeatOnAck(this.heartbeat, now);
    const kv = this.ctx.storage.kv;
    writeGateway(kv, { ...readGateway(kv, now), last_ack_at: now });
  }

  // Every dispatch advances seq inside one transaction (spec §6.4); wave 11 adds the ingest
  // to the same transaction.
  private onDispatch(message: GatewayDispatchPayload, now: number): void {
    const kv = this.ctx.storage.kv;
    this.ctx.storage.transactionSync(() => {
      let store: GatewayStore = { ...readGateway(kv, now), seq: message.s, last_event_at: now };
      if (message.t === GatewayDispatchEvents.Ready) {
        store = withStatus(
          {
            ...store,
            session_id: message.d.session_id,
            resume_gateway_url: message.d.resume_gateway_url,
            bot_user_id: message.d.user.id,
            backoff_attempt: 0,
            backoff_until: null,
          },
          "connected",
          null,
          now,
        );
        log("ready", { guilds: message.d.guilds.length });
      }
      writeGateway(kv, store);
    });
  }

  private sendHeartbeat(now: number): void {
    if (this.socket === null || this.heartbeat === null) return;
    const kv = this.ctx.storage.kv;
    const store = readGateway(kv, now);
    this.socket.send(heartbeatPayload(store.seq));
    this.heartbeat = heartbeatOnSend(this.heartbeat, now);
    writeGateway(kv, { ...store, last_heartbeat_at: now });
  }

  private onClose(socket: WebSocket, code: number | undefined, reason: string): void {
    // A socket we already replaced through dropSocket(): nothing to do.
    if (socket !== this.socket) return;
    this.socket = null;
    this.heartbeat = null;
    log("socket_closed", { code, reason });
    this.scheduleReconnect(reason === "" ? `close_${code ?? "unknown"}` : reason);
  }

  private dropSocket(): void {
    const socket = this.socket;
    this.socket = null;
    this.heartbeat = null;
    if (socket === null) return;
    try {
      socket.close(1000, "replaced");
    } catch {
      // Already closed by the other side.
    }
  }

  // Exponential backoff (spec §5.7); the alarm calls connect() when it elapses.
  private scheduleReconnect(reason: string): void {
    const now = Date.now();
    const kv = this.ctx.storage.kv;
    const store = readGateway(kv, now);
    const delay = backoffDelayMs(store.backoff_attempt);
    const next = { ...store, backoff_attempt: store.backoff_attempt + 1, backoff_until: now + delay };
    writeGateway(kv, withStatus(next, "backoff", reason, now));
    log("backoff", { attempt: next.backoff_attempt, delay_ms: delay, reason });
    this.scheduleAlarm(now);
  }

  // A close code only a human can fix: try again in an hour to protect the IDENTIFY budget.
  private fail(store: GatewayStore, reason: string, now: number): void {
    const failed = { ...store, backoff_until: now + FATAL_RETRY_MS };
    writeGateway(this.ctx.storage.kv, withStatus(failed, "fatal", reason, now));
    log("fatal", { reason });
    this.scheduleAlarm(now);
  }

  // One alarm for every deadline: the earliest of the next heartbeat and the reconnect.
  private scheduleAlarm(now: number): void {
    const store = readGateway(this.ctx.storage.kv, now);
    const deadlines = [this.heartbeat?.nextDueAt, store.backoff_until].filter(
      (at): at is number => typeof at === "number",
    );
    if (deadlines.length === 0) return;
    void this.ctx.storage.setAlarm(Math.floor(Math.min(...deadlines)));
  }

  private guildCount(): number {
    return (
      this.db.select({ n: count() }).from(guilds).where(eq(guilds.available, true)).get()?.n ?? 0
    );
  }
}
```

```ts
import type { PresenceSession, PresenceStatus } from "@migiwa/db";

import type { PresenceLike, SessionOp } from "./types";

const TRACKED: ReadonlySet<string> = new Set(["online", "idle", "dnd"]);

// Discord also sends "offline" and (for the bot itself) "invisible"; both mean "not here".
export function presenceStatus(status: string | undefined): PresenceStatus | null {
  return status !== undefined && TRACKED.has(status) ? (status as PresenceStatus) : null;
}

// Spec §6.3, PRESENCE_UPDATE / status. The partial unique index guarantees at most one open
// row per (guild, user), so `find` is enough.
export function reducePresenceStatus(
  open: PresenceSession[],
  d: PresenceLike,
  received_at: number,
): SessionOp[] {
  const current = open.find((row) => row.guild_id === d.guild_id && row.user_id === d.user.id);
  const next = presenceStatus(d.status);
  if (current !== undefined && current.status === next) return [];
  const ops: SessionOp[] = [];
  if (current !== undefined) {
    ops.push({
      kind: "close",
      table: "presence",
      id: current.id,
      ended_at: received_at,
      end_reason: next === null ? "offline" : "status_change",
    });
  }
  if (next !== null) {
    ops.push({
      kind: "open",
      table: "presence",
      row: {
        guild_id: d.guild_id,
        user_id: d.user.id,
        status: next,
        client_desktop: d.client_status?.desktop ?? null,
```

```ts
import type { ActivitySession } from "@migiwa/db";
import type { GatewayActivity } from "discord-api-types/v10";

import { presenceStatus } from "./presence";

import type { PresenceLike, SessionOp } from "./types";

// Discord marks activity.id as unstable, so identity is (type, application_id ?? name).
export const activityKey = (activity: GatewayActivity): string =>
  activity.application_id ?? activity.name;

const identity = (type: number, key: string): string => `${type}:${key}`;

// Spec §6.3, PRESENCE_UPDATE / activities: a set difference between the open rows and the
// activities in the payload. Offline closes everything.
export function reduceActivities(
  open: ActivitySession[],
  d: PresenceLike,
  received_at: number,
): SessionOp[] {
  const offline = presenceStatus(d.status) === null;
  const wanted = offline ? [] : (d.activities ?? []);
  const mine = open.filter((row) => row.guild_id === d.guild_id && row.user_id === d.user.id);
  const ops: SessionOp[] = [];
  const seen = new Set<string>();
  for (const activity of wanted) {
    const key = activityKey(activity);
    const id = identity(activity.type, key);
    // Discord can list the same application twice (e.g. two Spotify entries); first one wins.
    if (seen.has(id)) continue;
    seen.add(id);
    const row = mine.find((r) => identity(r.activity_type, r.activity_key) === id);
    const state = activity.state ?? null;
    const details = activity.details ?? null;
    if (row === undefined) {
      ops.push({
        kind: "open",
        table: "activity",
        row: {
          guild_id: d.guild_id,
          user_id: d.user.id,
          activity_type: activity.type,
          activity_key: key,
          application_id: activity.application_id ?? null,
          name: activity.name,
          state,
          details,
          started_at: activity.created_at,
        },
      });
    } else if (row.state !== state || row.details !== details) {
      ops.push({ kind: "update", table: "activity", id: row.id, patch: { state, details } });
    }
  }
  for (const row of mine) {
    if (seen.has(identity(row.activity_type, row.activity_key))) continue;
    ops.push({
      kind: "close",
      table: "activity",
      id: row.id,
      ended_at: received_at,
      end_reason: offline ? "offline" : "activity_end",
    });
  }
  return ops;
}
```

```ts
import type { VoiceSession } from "@migiwa/db";

import type { SessionOp, VoiceFlags, VoiceStateLike } from "./types";

const FLAG_NAMES = [
  "self_mute",
  "self_deaf",
  "mute",
  "deaf",
  "self_stream",
  "self_video",
  "suppress",
] as const;

const flagsOf = (d: VoiceStateLike): VoiceFlags => ({
  self_mute: d.self_mute,
  self_deaf: d.self_deaf,
  mute: d.mute,
  deaf: d.deaf,
  self_stream: d.self_stream ?? false,
  self_video: d.self_video,
  suppress: d.suppress,
});

// Spec §6.3, VOICE_STATE_UPDATE. `guild_id` is passed separately because GUILD_CREATE's
// voice_states[] entries do not carry it.
export function reduceVoice(
  open: VoiceSession[],
  guild_id: string,
  d: VoiceStateLike,
  received_at: number,
): SessionOp[] {
  const row = open.find((r) => r.guild_id === guild_id && r.user_id === d.user_id);
  const channel = d.channel_id;
  const openOp = (channel_id: string): SessionOp => ({
    kind: "open",
    table: "voice",
    row: {
      guild_id,
      user_id: d.user_id,
      channel_id,
      discord_session_id: d.session_id,
      started_at: received_at,
      ...flagsOf(d),
    },
  });
  if (row === undefined) return channel === null ? [] : [openOp(channel)];
  if (channel === null) {
    return [{ kind: "close", table: "voice", id: row.id, ended_at: received_at, end_reason: "leave" }];
  }
  if (channel !== row.channel_id) {
    return [
      { kind: "close", table: "voice", id: row.id, ended_at: received_at, end_reason: "move" },
      openOp(channel),
    ];
  }
  const flags = flagsOf(d);
  const patch: Partial<VoiceFlags> = {};
  for (const name of FLAG_NAMES) {
    if (row[name] !== flags[name]) patch[name] = flags[name];
  }
  return Object.keys(patch).length === 0
    ? []
    : [{ kind: "update", table: "voice", id: row.id, patch }];
}
```

```ts
    guild_id: d.id,
    name: d.name,
    member_count: d.member_count,
    large: d.large,
    available: true,
    last_snapshot_at: received_at,
  };
  const ops: SessionOp[] = [];
  const present = new Set<string>();
  const inVoice = new Set<string>();
  for (const presence of d.presences) {
    present.add(presence.user.id);
    const like = { ...presence, guild_id: d.id };
    ops.push(
      ...reducePresenceStatus(open.presence, like, received_at),
      ...reduceActivities(open.activity, like, received_at),
    );
  }
  for (const voice of d.voice_states) {
    inVoice.add(voice.user_id);
    ops.push(...reduceVoice(open.voice, d.id, voice, received_at));
  }
  const ended_at = disconnected_at ?? received_at;
  if (d.member_count <= PRESENCE_SNAPSHOT_LIMIT) {
    for (const row of open.presence) {
      if (present.has(row.user_id)) continue;
      ops.push({ kind: "close", table: "presence", id: row.id, ended_at, end_reason: "snapshot_missing" });
    }
    for (const row of open.activity) {
      if (present.has(row.user_id)) continue;
      ops.push({ kind: "close", table: "activity", id: row.id, ended_at, end_reason: "snapshot_missing" });
    }
  }
  for (const row of open.voice) {
    if (inVoice.has(row.user_id)) continue;
    ops.push({ kind: "close", table: "voice", id: row.id, ended_at, end_reason: "snapshot_missing" });
  }
  return { guild, ops };
}

// Spec §6.3, GUILD_DELETE: an outage (`unavailable: true`) changes nothing here (apps/bot
// flips guilds.available); being removed closes every open row.
export function reduceGuildDelete(
  open: OpenRows,
  d: GatewayGuildDeleteDispatchData,
  received_at: number,
): SessionOp[] {
  if (d.unavailable === true) return [];
  return [
    ...open.presence.map(
      (row): SessionOp => ({ kind: "close", table: "presence", id: row.id, ended_at: received_at, end_reason: "guild_removed" }),
    ),
    ...open.activity.map(
      (row): SessionOp => ({ kind: "close", table: "activity", id: row.id, ended_at: received_at, end_reason: "guild_removed" }),
    ),
    ...open.voice.map(
      (row): SessionOp => ({ kind: "close", table: "voice", id: row.id, ended_at: received_at, end_reason: "guild_removed" }),
    ),
  ];
}
```

```ts
import type { DatabaseClient } from "@migiwa/db";
import type { SessionOp } from "@migiwa/sessionizer";

import { activity_sessions, presence_sessions, voice_sessions } from "@migiwa/db";
import { eq } from "drizzle-orm";

// Turns the sessionizer's ops into Drizzle statements. Called inside the dispatch transaction,
// so a failure rolls back the whole event (spec §6.4).
export function applyOps(db: DatabaseClient, ops: SessionOp[]): void {
  for (const op of ops) {
    if (op.kind === "open") {
      if (op.table === "presence") db.insert(presence_sessions).values(op.row).run();
      else if (op.table === "activity") db.insert(activity_sessions).values(op.row).run();
      else db.insert(voice_sessions).values(op.row).run();
    } else if (op.kind === "close") {
      const patch = { ended_at: op.ended_at, end_reason: op.end_reason };
      if (op.table === "presence") {
        db.update(presence_sessions).set(patch).where(eq(presence_sessions.id, op.id)).run();
      } else if (op.table === "activity") {
        db.update(activity_sessions).set(patch).where(eq(activity_sessions.id, op.id)).run();
      } else {
        db.update(voice_sessions).set(patch).where(eq(voice_sessions.id, op.id)).run();
      }
    } else if (op.table === "activity") {
      db.update(activity_sessions).set(op.patch).where(eq(activity_sessions.id, op.id)).run();
    } else {
      db.update(voice_sessions).set(op.patch).where(eq(voice_sessions.id, op.id)).run();
    }
  }
}
```

```ts
import type { DatabaseClient } from "@migiwa/db";
import type { GatewayDispatchPayload } from "discord-api-types/v10";

import { events, guilds } from "@migiwa/db";
import { reduce, reduceGuildCreate, reduceGuildDelete } from "@migiwa/sessionizer";
import { Result, TaggedError } from "better-result";
import { GatewayDispatchEvents } from "discord-api-types/v10";
import { eq } from "drizzle-orm";

import { applyOps } from "./apply-ops";
import { loadOpenRows } from "./open-rows";

export type IngestOutcome = "ingested" | "ignored";
export type GuildFilter = (guild_id: string) => boolean;

// A dispatch whose required ids are missing on the wire (spec §5.4, D12). Counted, never thrown.
export class MalformedDispatch extends TaggedError("MalformedDispatch")<{
  event: string;
  missing: string;
  message: string;
}> {}

const missing = (event: string, field: string): Result<never, MalformedDispatch> =>
  Result.err(new MalformedDispatch({ event, missing: field, message: `${event} without ${field}` }));

// DISCORD_GUILD_IDS: empty keeps every guild (spec §8).
export function guildFilter(raw: string): GuildFilter {
  const ids = new Set(
    raw
      .split(",")
      .map((id) => id.trim())
      .filter((id) => id !== ""),
  );
  return ids.size === 0 ? () => true : (guild_id) => ids.has(guild_id);
}

// The wire may disagree with discord-api-types; ids the rules depend on are re-read as
// unknown before use (spec §5.4). Returns null for anything that is not a non-empty string.
function idAt(value: unknown, ...path: string[]): string | null {
  let current: unknown = value;
  for (const key of path) {
    if (typeof current !== "object" || current === null) return null;
    current = (current as Record<string, unknown>)[key];
  }
  return typeof current === "string" && current !== "" ? current : null;
}

// Runs inside the dispatch transaction (spec §6.4). Ok says what happened so the caller can
// count it; a malformed payload is an Err with the missing field, never an exception.
export function ingestDispatch(
  db: DatabaseClient,
  message: GatewayDispatchPayload,
  received_at: number,
  disconnected_at: number | null,
  allow: GuildFilter,
): Result<IngestOutcome, MalformedDispatch> {
  switch (message.t) {
    case GatewayDispatchEvents.PresenceUpdate: {
      const { d } = message;
      const guild_id = idAt(d, "guild_id");
      const user_id = idAt(d, "user", "id");
      if (guild_id === null) return missing(message.t, "guild_id");
      if (user_id === null) return missing(message.t, "user.id");
      if (!allow(guild_id)) return Result.ok("ignored");
      db.insert(events)
        .values({ received_at, seq: message.s, type: message.t, guild_id, user_id, payload: d })
        .run();
      const ops = reduce(loadOpenRows(db, guild_id, user_id), { t: "PRESENCE_UPDATE", d }, received_at);
      applyOps(db, ops);
      return Result.ok("ingested");
    }
    case GatewayDispatchEvents.VoiceStateUpdate: {
      const { d } = message;
      const guild_id = idAt(d, "guild_id");
      const user_id = idAt(d, "user_id");
      if (guild_id === null) return missing(message.t, "guild_id");
      if (user_id === null) return missing(message.t, "user_id");
      if (!allow(guild_id)) return Result.ok("ignored");
      db.insert(events)
        .values({ received_at, seq: message.s, type: message.t, guild_id, user_id, payload: d })
        .run();
      const ops = reduce(loadOpenRows(db, guild_id, user_id), { t: "VOICE_STATE_UPDATE", d }, received_at);
      applyOps(db, ops);
      return Result.ok("ingested");
    }
    case GatewayDispatchEvents.GuildCreate: {
      const { d } = message;
      const guild_id = idAt(d, "id");
      if (guild_id === null) return missing(message.t, "id");
      if (!allow(guild_id)) return Result.ok("ignored");
      const { guild, ops } = reduceGuildCreate(loadOpenRows(db, guild_id), d, received_at, disconnected_at);
      db.insert(guilds)
        .values({ ...guild, first_seen_at: received_at })
        .onConflictDoUpdate({ target: guilds.guild_id, set: guild })
        .run();
      // Trimmed on purpose (spec §6.2): the full GUILD_CREATE carries every member and channel.
      const payload = {
        id: guild_id,
        name: d.name,
        member_count: d.member_count,
        large: d.large,
        presences_count: d.presences.length,
        voice_states_count: d.voice_states.length,
      };
      db.insert(events)
        .values({ received_at, seq: message.s, type: message.t, guild_id, user_id: null, payload })
        .run();
      applyOps(db, ops);
      return Result.ok("ingested");
    }
    case GatewayDispatchEvents.GuildDelete: {
      const { d } = message;
      const guild_id = idAt(d, "id");
      if (guild_id === null) return missing(message.t, "id");
      if (!allow(guild_id)) return Result.ok("ignored");
      db.update(guilds).set({ available: false }).where(eq(guilds.guild_id, guild_id)).run();
      applyOps(db, reduceGuildDelete(loadOpenRows(db, guild_id), d, received_at));
      return Result.ok("ingested");
    }
    default:
      return Result.ok("ignored");
  }
}
```

```ts
  // a RESUME after a crash replays exactly the events that were not applied (spec §6.4).
  private onDispatch(message: GatewayDispatchPayload, now: number): void {
    const kv = this.ctx.storage.kv;
    this.ctx.storage.transactionSync(() => {
      let store: GatewayStore = { ...readGateway(kv, now), seq: message.s, last_event_at: now };
      if (message.t === GatewayDispatchEvents.Ready) {

          {
            ...store,
            session_id: message.d.session_id,
            resume_gateway_url: message.d.resume_gateway_url,
            bot_user_id: message.d.user.id,
            backoff_attempt: 0,
            backoff_until: null,
          },
          "connected",
          null,
          now,
        );
        log("ready", { guilds: message.d.guilds.length });
      } else if (message.t === GatewayDispatchEvents.Resumed) {
        store = withStatus({ ...store, backoff_attempt: 0, backoff_until: null }, "connected", null, now);
        log("resumed", { seq: message.s });
      }
      const awaySince =
        store.disconnected_at !== null && now - store.status_since < SNAPSHOT_WINDOW_MS
          ? store.disconnected_at
          : null;
      const outcome = ingestDispatch(this.db, message, now, awaySince, this.allowGuild);
      this.count(
        outcome.match({
          ok: (kind) => `${message.t}:${kind}`,
          err: (error) => `${message.t}:dropped:${error.missing}`,
        }),
      );
      writeGateway(kv, store);
    });
```

```ts
import type { DatabaseClient } from "@migiwa/db";

import { activity_sessions, events, presence_sessions, voice_sessions } from "@migiwa/db";
import { and, count, isNotNull, isNull, lt } from "drizzle-orm";

export interface PurgeOptions {
  rawEventDays: number;
  retentionDays: number;
}

export interface PurgeCounts {
  events: number;
  sessions: number;
  timed_out: number;
}

export const NEXT_PURGE_KEY = "next_purge_at";

const DAY_MS = 86_400_000;
// A session open this long is a missed close, not a week-long call (spec §6.5).
const OPEN_TIMEOUT_DAYS = 7;

type SessionTable = typeof presence_sessions | typeof activity_sessions | typeof voice_sessions;

// Counts first, then deletes: drizzle's durable-sqlite driver does not report affected rows.
function purgeSessions(db: DatabaseClient, table: SessionTable, now: number, closedBefore: number, openBefore: number): [number, number] {
  const closedOld = and(isNotNull(table.ended_at), lt(table.ended_at, closedBefore));
  const closed = db.select({ n: count() }).from(table).where(closedOld).get()?.n ?? 0;
  db.delete(table).where(closedOld).run();
  const stuck = and(isNull(table.ended_at), lt(table.started_at, openBefore));
  const timedOut = db.select({ n: count() }).from(table).where(stuck).get()?.n ?? 0;
  db.update(table).set({ ended_at: now, end_reason: "timeout" }).where(stuck).run();
  return [closed, timedOut];
}

// Spec §6.5. Called inside a transaction by alarm().
export function purge(db: DatabaseClient, now: number, options: PurgeOptions): PurgeCounts {
  const eventsBefore = now - options.rawEventDays * DAY_MS;
  const sessionsBefore = now - options.retentionDays * DAY_MS;
  const openBefore = now - OPEN_TIMEOUT_DAYS * DAY_MS;
  const staleEvents = lt(events.received_at, eventsBefore);
  const counts: PurgeCounts = {
    events: db.select({ n: count() }).from(events).where(staleEvents).get()?.n ?? 0,
    sessions: 0,
    timed_out: 0,
  };
  db.delete(events).where(staleEvents).run();
  for (const table of [presence_sessions, activity_sessions, voice_sessions]) {
    const [closed, timedOut] = purgeSessions(db, table, now, sessionsBefore, openBefore);
    counts.sessions += closed;
    counts.timed_out += timedOut;
  }
  return counts;
}

const days = (raw: string, fallback: number): number => {
  const value = Number(raw);
  return Number.isFinite(value) && value > 0 ? value : fallback;
};

export function purgeOptions(env: Cloudflare.Env): PurgeOptions {
  return {
    rawEventDays: days(env.RAW_EVENT_RETENTION_DAYS, 7),
    retentionDays: days(env.RETENTION_DAYS, 30),
  };
}

// The purge deadline lives beside the gateway state in kv; the first one is a day after the
// object is first asked.
export function nextPurgeAt(kv: SyncKvStorage, now: number): number {
  const stored = kv.get<number>(NEXT_PURGE_KEY) ?? null;
  if (stored !== null) return stored;
  const first = now + DAY_MS;
  kv.put(NEXT_PURGE_KEY, first);
  return first;
}
```

```ts
import type { TableInfo } from "@migiwa/gateway";

// One line of meaning per table the schema is expected to have. An unknown table (a future
// migration) still shows up with its columns, so the description never hides data.
const TABLE_NOTES: Record<string, string> = {
  guilds:
    "guilds the bot can see; available is 0 during a Discord outage or after the bot was removed.",
  events:
    "raw Gateway dispatches kept for a few days; payload is JSON, read it with json_extract(payload, '$.field').",
  presence_sessions:
    "one row per stretch of one status (online / idle / dnd) for a user in a guild. Stored per guild: a user in three guilds has three rows, so count people with COUNT(DISTINCT user_id).",
  activity_sessions:
    "one row per stretch of one activity (game, Spotify, custom status, …) for a user in a guild; activity_type is Discord's 0–5.",
  voice_sessions:
    "one row per stay in one voice channel; moving channels closes the row and opens a new one. Flags hold the last observed value.",
};

const CONSTRAINT = /^(?:PRIMARY|UNIQUE|CHECK|FOREIGN|CONSTRAINT)\b/i;
const IDENTIFIER = /^[`"[]?([A-Za-z_][A-Za-z0-9_]*)/;

// Column names out of a CREATE TABLE statement as sqlite_master stores it. Splits on commas,
// which is fine for drizzle-kit's output (no DEFAULT expressions with commas).
export function columnsOf(createSql: string): string[] {
  const body = createSql.slice(createSql.indexOf("(") + 1, createSql.lastIndexOf(")"));
  return body
    .split(",")
    .map((part) => part.trim())
    .filter((part) => part !== "" && !CONSTRAINT.test(part))
    .map((part) => IDENTIFIER.exec(part)?.[1] ?? "")
    .filter((name) => name !== "");
}

// The query tool's description (spec §7.2): what the tables mean plus the conventions a model
// needs to write correct SQL against them. Built from the live sqlite_master on every request.
export function buildDescription(tables: TableInfo[]): string {
  const lines = [
    "Run one read-only SQL statement (SELECT, WITH or EXPLAIN) against the Discord bot's SQLite " +
      "database of presence, activity and voice sessions. Returns { columns, rows, rows_read, truncated }.",
    "",
    "Rules:",
    "- Timestamps are Unix milliseconds: datetime(started_at / 1000, 'unixepoch').",
    "- An open session has ended_at IS NULL. Its duration so far is COALESCE(ended_at, unixepoch() * 1000) - started_at.",
    "- end_reason is one of status_change, offline, activity_end, leave, move, snapshot_missing (the user was gone when the bot reconnected), guild_removed, timeout.",
    "- Presence and activity rows are per guild; use COUNT(DISTINCT user_id) for people.",
    "- events.payload is JSON; read fields with json_extract(payload, '$.field').",
    "- Always add a LIMIT; results stop at 10,000 rows.",
    "",
    "Tables:",
  ];
  for (const table of tables) {
    const note = TABLE_NOTES[table.name];
    const columns = columnsOf(table.sql).join(", ");
    lines.push(note === undefined ? `- ${table.name}(${columns})` : `- ${table.name}(${columns}): ${note}`);
  }
  return lines.join("\n");
}
```

````markdown
3. Deploy the MCP Worker with a bearer token of your choosing:

   ```sh
   bun run --cwd apps/remote-mcp wrangler secret put API_TOKEN
   bun run --cwd apps/remote-mcp wrangler deploy
   ```

4. Point your MCP client at `https://migiwa-remote-mcp.<your-subdomain>.workers.dev/mcp` with
   `Authorization: Bearer <API_TOKEN>`. `GET /health` on the same host tells you whether the
   bot is connected.
````
